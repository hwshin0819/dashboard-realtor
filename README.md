# 중개사무소 개폐업 대시보드 (v0.1 · 틀 + 목업 데이터)

공공데이터(브이월드 디지털트윈 국토 등)를 활용해 중개사무소 개업/폐업/영업중 현황을
월별·지역별로 확인하기 위한 대시보드입니다.

**지금 버전은 화면 틀과 가짜(목업) 데이터로 만든 1차 버전입니다.**
브이월드 API에서 실제 데이터를 가져오는 로직과 실제 배치 스케줄 실행기는
다음 단계에서 이어서 붙일 예정입니다. 지금은 화면 구성, 로그인/권한 관리,
설정 저장 방식이 잘 맞는지 먼저 확인하는 것이 목적입니다.

## 처음 실행하는 방법

1. 이 폴더 안의 **`run.bat`** 파일을 더블클릭하세요.
2. 처음 실행할 때는 파이썬 가상환경을 만들고 필요한 패키지를 설치하느라
   1~2분 정도 걸릴 수 있습니다. (인터넷 연결 필요)
3. 설치가 끝나면 검은 화면(명령창)에 서버가 실행 중이라는 메시지가 나옵니다.
   이 창을 닫지 않아야 대시보드가 계속 켜져 있습니다.
4. 브라우저에서 아래 주소로 접속합니다.
   - 이 컴퓨터에서: `http://localhost:9000`
   - 같은 사무실 네트워크의 다른 컴퓨터에서: `http://192.168.14.117:9000`
5. Windows 방화벽 경고 창이 뜨면 **"액세스 허용"** 을 눌러주세요.
   (허용하지 않으면 다른 컴퓨터에서 접속이 안 됩니다)

> 참고: `192.168.14.117` 은 이 대시보드를 실행하는 컴퓨터의 사내망(LAN) 주소입니다.
> 만약 이 컴퓨터의 IP 주소가 바뀌면, 위 주소도 그에 맞게 바뀝니다
> (명령 프롬프트에서 `ipconfig` 로 확인 가능한 "IPv4 주소").

## 첫 로그인 정보

- 아이디: `admin`
- 비밀번호: `changeme123`

**처음 로그인하면 바로 "관리자 관리" 탭에서 비밀번호를 바꾸거나,
본인 계정을 새로 만들고 이 기본 계정 비밀번호는 재설정해두는 것을 권장합니다.**

## 누가 볼 수 있나요? (접속 권한)

- 이 대시보드는 **등록된 아이디/비밀번호가 있는 사람만** 로그인해서 볼 수 있습니다.
- "관리자 관리" 탭(관리자 계정만 보임)에서 볼 사람을 자유롭게 추가/삭제할 수 있습니다.
- 역할은 `admin`(관리자 관리 가능) / `user`(일반 조회) 두 가지입니다.
- 누가 언제 로그인했는지는 "접속 로그" 탭에서 확인할 수 있습니다.

## 화면 구성

| 탭 | 설명 |
|---|---|
| 개요 | 월별·지역별 개업/폐업/영업중 현황 (현재는 목업 데이터) |
| 웹훅 관리 | 개업/폐업 등 이벤트 발생 시 알림 보낼 웹훅 URL 관리 |
| 수집 대상 | 어떤 지역의 데이터를 수집할지 설정 |
| 수집테스트 | 실제 연동 전, 수집 흐름을 미리 테스트 (현재는 결과가 무작위 생성) |
| 배치 스케줄 | 수집/집계 작업의 실행 주기 설정 (현재는 설정 저장만 되고 실제 실행기는 없음) |
| 관리자 관리 | 로그인 계정 추가/삭제, 비밀번호 재설정 (admin 전용) |
| 접속 로그 | 로그인/로그아웃 기록 |

## 자주 묻는 질문

**Q. 창을 닫으면 어떻게 되나요?**
서버가 종료되어 다른 사람들도 더 이상 접속할 수 없습니다. 계속 켜두려면 창을 닫지 마세요.

**Q. 컴퓨터를 재부팅해도 자동으로 켜지게 하고 싶어요.**
지금 버전은 수동 실행(run.bat 더블클릭) 방식입니다. 자동 시작이 필요하면
Windows 작업 스케줄러 등록을 도와드릴 수 있으니 말씀해주세요.

**Q. 포트 9000이 이미 사용 중이라고 나와요.**
`.streamlit/config.toml` 파일의 `port = 9000` 값을 다른 숫자(예: 9001)로 바꾸고
다시 실행해주세요.
